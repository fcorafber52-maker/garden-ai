\# garden-ai



My AI garden: local AI, memo, autonomous gardening agents, and Tomatera, cloud memory with Cloudflare Workers based on second-brain by Rahil Pirani.



\# This repository is the entry point to my personal local AI ecosystem. It documents and shares the following projects:



garden-ai: this website.

memo: local memory with Obsidian and agents as private homes.

Tomatera: cloud memory adapted from second-brain by Rahil Pirani.

Agents: deep, Buffy, MimoCode, OpenCode, Freebuff.

Reflections: notes, experiments, and learnings about local AI.



\# Agents and their roles



deepseek: knowledge pipeline and export.

Buffy: Tomatera gardener.

Freebuff: agent on WSL2.

MimoCode: Xiaomi text processing and memory.

OpenCode: main agent on Windows.

Kilo CLI: autonomous auxiliary agent.

Cline: autonomous auxiliary agent.
